# 🪖 Smart Helmet - SOS Alert System

An IoT-based smart helmet designed to enhance rider safety by automatically detecting accidents and sending real-time emergency alerts with live GPS location.

🏆 **2nd Place** — Christ University Project Expo (Innovation in Real-Time Rider Safety & Emergency Response)

---

## 📌 Overview

Road accidents often go unnoticed until it's too late — especially for solo riders. This project solves that problem by embedding a vibration-based accident detection system into a helmet, which automatically triggers an SOS alert with the rider's live location the moment a crash is detected.

---

## ⚙️ How It Works

1. A **vibration sensor** mounted on the helmet continuously monitors for sudden impacts consistent with a crash.
2. Upon detecting a potential accident, the system captures the current **GPS coordinates**.
3. A **GSM module** automatically sends an SOS SMS alert — including the live location — to a pre-configured emergency contact.
4. This enables faster emergency response, even when the rider is unable to call for help themselves.

---

## 🛠️ Tech Stack & Components

- **Arduino IDE** — firmware development
- **Vibration Sensor** — accident/impact detection
- **GPS Module** — real-time location tracking
- **GSM Module** — SMS-based emergency alerting
- **Microcontroller** (Arduino board)

---

## 🚀 Features

- Real-time accident detection using vibration sensing
- Automatic SOS alert with live GPS location — no manual action needed
- Low-cost, lightweight, and easily integrable into standard helmets
- Designed for real-world reliability in emergency scenarios
